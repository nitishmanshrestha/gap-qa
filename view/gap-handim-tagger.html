1

Start your file

Enter the name, pick the level (project is optional), then click Create new file or Open existing.

  • Save as the suggested name, e.g. your-name-l3.json.
  • Existing file: loaded. New file: created. Choose Replace if asked; your data is kept.
  • Edge or Chrome only.
2

Check your level

Competencies are critical, important or supporting for your level. Cover the critical ones first. ASE has no tier list yet.

Switching the target level shows only that level's artifacts and coverage.

3

Add an artifact

One piece of work someone could verify.

  • Artifact: what you shipped
  • Problem it solved and Description: required
  • Competencies: required, what it proves
  • Claim story: auto-drafted from the fields and ticked competencies; edit it
  • Impact (optional): before, after, how measured
  • Proof (optional): links, screenshots or a flow

Short on time? Type the artifact name, the problem it solved and a few words of description, then click Suggest competency touched to tick likely competencies (a keyword match, so check each one). Copy for agent copies the artifact for the gap-artifact-polisher agent, which suggests competencies from the knowledge base and lists what is missing.

Example

Artifact: PR review bot
Impact: PR-to-merge 26 hrs to 6 hrs (measured)
Proof: repo link, before/after numbers

4

Save and read coverage

Click Save artifact. Red tiles are critical competencies with no evidence yet. Save needs the name, problem, description and one competency; the form shows what is missing.

5

Review

Edit or delete artifacts. Drag the grip on an artifact to reorder it: the order sets the artifact numbers. Edited the JSON by hand? Switch back to this tab to reload it.

6

Export

Export HTML slides saves a folder with the slides (index.html, styles.css, data.json and images) named after you, your level and the time. Export Markdown opens a save dialog in your file's folder. Both use all ready artifacts for the current level. Agent drafts are excluded until you edit them and save here.

Draft claims with the agent (optional)

  1. In Copilot Chat, choose gap-artifact-polisher.
  2. Paste a document with one block per artifact: Point, Problem, Before, After, Consequence, Method (estimates only) and Proof.
  3. Complete any artifacts the agent lists as incomplete. It drafts the rest.
  4. Confirm the drafts. The agent writes source/your-name-le.json.
  5. Click Open existing and choose that file. Hand edits reload when you return to this tab.

Unfinished artifact? Say draft in the chat, or use Copy for agent with required items blank. The agent saves it as a draft and lists what is missing.

Limits
  • Links are not opened. Notes go to Copilot, so do not paste confidential customer data.
  • The agent suggests figure status, proof and competencies (first is primary). Check them in the review.
  • Agent claims carry createdAt 2026-11-06. To change it, edit the JSON and return to this tab.

Troubleshooting

Create new file is greyed out

Enter the candidate name.

Export Markdown downloads a file

The save dialog could not open. Find the file in your Downloads folder.

This browser cannot create or save data files

Open the app in Microsoft Edge or Chrome.

Access refused

Click Grant access and choose Allow. No prompt? IT policy may block it.

"File changed outside the app"

It was reloaded. Review and save again.

Where is my data?

Only in your JSON file. Keep a backup.
